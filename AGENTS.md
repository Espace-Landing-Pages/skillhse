# HSE Design System

## Язык

- Ответы, комментарии и саммари писать на русском языке.
- Код, названия файлов и технические термины оставлять на английском.

## Источник истины

- Для фирменного стиля использовать `SKILL.md` и `references/brand-guidelines.md`.
- При расхождении применять полное руководство `assets/official/guidelines/HSE-brandbook-2026-04-10.pdf`.
- Не заменять актуальный второй синий `#234B9B` старыми оттенками из веб-иллюстраций.

## Репозиторий

- Держать репозиторий закрытым.
- Хранить бинарные ассеты только через Git LFS согласно `.gitattributes`.
- Не добавлять секреты, токены и `.env`.
- Не публиковать логотипы, шрифты и полный asset bundle без проверки договорных прав.
- Не выполнять прямой деплой; использовать GitHub Actions, если он появится.

## Проверка

- После изменений запускать `python3 scripts/verify_package.py`.
- После изменений в skill запускать `quick_validate.py` из `skill-creator`.
