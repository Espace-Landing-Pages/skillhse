# HSE Design System

Применять фирменный стиль НИУ ВШЭ по полному руководству от 10.04.2026. Использовать этот skill как рабочий слой над официальным брендбуком, а не как замену согласованию с владельцем бренда.

## Обязательный порядок работы

1. Прочитать `references/legal-and-sources.md`, если задача включает копирование, публикацию, передачу или коммерческое использование ассетов.
2. Прочитать `references/brand-guidelines.md` перед созданием или аудитом визуального материала.
3. Прочитать `references/asset-map.md`, если нужны логотипы, шрифты, шаблоны или исходники для печати.
4. Определить носитель: digital, print, presentation, social media, merchandise или internal document.
5. Использовать актуальные токены из `assets/tokens/hse.tokens.json`; не извлекать цвета из старых SVG или скриншотов.
6. Выбрать готовый официальный ассет. Не перерисовывать логотип и не собирать его из текста.
7. Адаптировать реализацию к стеку и структуре целевого проекта, сохраняя его существующие компоненты и conventions.
8. Проверить результат по разделу «Проверка» ниже.

## Источник истины

Применять приоритет в таком порядке:

1. Письменные условия договора и согласование уполномоченного подразделения НИУ ВШЭ.
2. `assets/official/guidelines/HSE-brandbook-2026-04-10.pdf`.
3. Текущая страница `https://www.hse.ru/info/brandbook/`.
4. Архивные графические файлы из `assets/official/`.

При расхождении не смешивать версии. Для digital использовать основной синий `#0F2D69` и второй синий `#234B9B` из PDF 2026. Не брать `#254B9B` или `#374B9B` из старых веб-иллюстраций.

## Ассеты

- Использовать `assets/tokens/` для CSS и JSON-токенов.
- Использовать `assets/fonts/` для компактного набора HSE Sans и HSE Slab.
- Использовать `assets/official/logos/` для логотипов, знака, кампусных и международных версий.
- Использовать `assets/official/graphic-elements/` для аббревиатуры, девиза и маскота.
- Использовать `assets/official/templates/` для PowerPoint, Keynote и LaTeX.
- Использовать `assets/original-downloads/` только для проверки provenance или повторной распаковки.

Для digital предпочитать SVG. Для печати выбирать AI, EPS или PDF из каталога CMYK/PANTONE. Всегда выбирать отдельную версию для светлого или темного фона; не перекрашивать SVG вручную.

## Быстрый старт для web

Скопировать компактный web kit в целевой проект:

```bash
python3 scripts/install_web_kit.py <project>/public/hse-brand
```

Подключить `css/hse-fonts.css` и `css/hse-tokens.css`. Использовать `var(--hse-font-sans)` как основной стек и `var(--hse-font-slab)` только там, где выбран Slab. Использовать Thin и Black преимущественно в крупном кегле.

Не запускать `--force`, пока не проверены существующие файлы в целевом каталоге.

## Ограничения

- Не менять цвет, пропорции, шрифт, внутренние элементы или композицию логотипа.
- Не использовать старые версии логотипа, монограмму без круга или собственноручно набранный descriptor.
- Не использовать дополнительные цвета как основные; ограничивать их суммарно 25% креатива.
- Не смешивать несколько акцентных триад одновременно.
- Не ставить основной логотип внутрь паттерна; знак допустим по правилам брендбука.
- Не считать доступность автоматически выполненной: проверять контраст текста и логотипа на фактическом фоне.
- Не распространять пакет публично без проверки договорных прав и товарных знаков.

## Проверка

Перед выдачей результата:

1. Проверить выбранную версию логотипа, охранную зону, минимальный размер и отступ от края.
2. Проверить точные HEX/RGB для digital или CMYK/PANTONE для печати.
3. Проверить, что акценты занимают не более 25% и используется не более одной триады.
4. Проверить контраст логотипа не ниже WCAG AA 4.5:1; отдельно проверить текст по требованиям целевого продукта.
5. Проверить HSE Sans/HSE Slab, доступные начертания и отсутствие synthetic bold/italic.
6. Проверить русскую микротипографику: «елочки», „лапки“, длинное тире, интервальное тире, неразрывные и волосяные пробелы.
7. Проверить, что на сувенирной продукции все надписи выполнены на русском языке и кириллицей.
8. Для нового маскота, подстиля, подразделенческого логотипа или спорной коллаборации явно запросить согласование у ответственного блока ВШЭ.

## Обновление пакета

Для повторной нормализации исходных архивов выполнить:

```bash
python3 scripts/unpack_brand_assets.py
```

После обновления официального брендбука повторно сверить `references/brand-guidelines.md`, токены и `references/source-inventory.md`. Не обновлять токены только по цвету на экране или по старому SVG.
